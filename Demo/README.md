# Student Performance Prediction

This project is a classroom demonstration of a supervised classification workflow that predicts whether a student is **At Risk** or **Not At Risk** using four academic indicators. The dataset is synthetic and must not be used for real student decisions.

## Project files

- `student_performance.csv` — dataset used by KNIME and Python
- `Student_Performance_Prediction.knwf` — exported KNIME workflow **to be added after completing KNIME**
- `train_model.py` — compares three algorithms and trains the selected pipeline
- `model_comparison.csv` — cross-validation metrics generated by the training script
- `student_performance_model.joblib` — saved trained pipeline
- `app.py` — Streamlit prediction interface
- `reflection.md` — limitations and responsible-use reflection
- `evidence.pdf` — screenshots of the completed workflow and application **to be added**

## Dataset and prediction target

Input features:

- `attendance`
- `quiz_score`
- `assignment_score`
- `exam_score`

Target column: `risk_status`

Excluded column: `student_id`, because it is only a row identifier and should not influence predictions.

## Algorithms compared

1. Logistic Regression
2. Decision Tree
3. Random Forest

The Python comparison uses stratified five-fold cross-validation with random state `42`. Accuracy, precision, recall, and F1-score are reported for the **At Risk** class. Logistic Regression is saved as the final classroom model because it is simple and interpretable; the small synthetic dataset is not sufficient for deployment.

## Run the Python workflow

Use Python 3.10 or newer. From inside the `Demo` folder, run:

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

Install dependencies and train the models:

```bash
pip install -r requirements.txt
python train_model.py
```

This recreates `model_comparison.csv` and `student_performance_model.joblib`.

## Run the Streamlit application

```bash
streamlit run app.py
```

Enter values from 0 to 100 for attendance, quiz score, assignment score, and examination score, then select **Predict**.

## Import and run the KNIME workflow

1. Download `Student_Performance_Prediction.knwf` and `student_performance.csv` from this folder.
2. Open KNIME Analytics Platform.
3. Select **File > Import KNIME Workflow** and choose the `.knwf` file.
4. Open the CSV Reader configuration.
5. Select the `student_performance.csv` file included in this repository.
6. Confirm that the six columns are detected and that the four score columns are numeric.
7. Execute all nodes and review the Scorer outputs for each algorithm.

The KNIME workflow should use this structure:

`CSV Reader → Column Filter → Partitioning/Cross Validation → Learners → Predictors → Scorers`

Configure the Column Filter to exclude `student_id`. Use `risk_status` as the target and compare Logistic Regression, Decision Tree, and Random Forest.

## Responsible use

This project is an educational demonstration. A prediction should only prompt human review and possible support. It must never be treated as a final judgment about a student.
